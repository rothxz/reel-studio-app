# Bundled fonts

Embedded into the binary by `src/theme.rs`. All are third-party open-source
fonts, used unmodified.

| File | Font | Licence |
| --- | --- | --- |
| `Nunito_*.ttf` | Nunito, © The Nunito Project Authors | SIL OFL 1.1, `OFL-Nunito.txt` |
| `IBMPlexMono_*.ttf` | IBM Plex Mono, © IBM Corp. | SIL OFL 1.1, `OFL-IBMPlexMono.txt` |
| `KantumruyPro_*.ttf` | Kantumruy Pro, © The Kantumruy Pro Project Authors (all UI text while the language is Khmer) | SIL OFL 1.1, `OFL-KantumruyPro.txt` |
| `Ionicons.ttf` | Ionicons icon font, © Ionic | MIT, as distributed in react-native-vector-icons (`MIT-react-native-vector-icons.txt`) |
| `MaterialCommunityIcons.ttf` | Material Design Icons, © Pictogrammers | Pictogrammers Free License (icons Apache 2.0, font SIL OFL 1.1) |

Icon glyphs are addressed by codepoint in `src/ui/icons.rs`.
